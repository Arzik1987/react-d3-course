# Docs

Each subfolder contains one standalone webpage for a course assignment.

Recommended structure for an assignment:

```text
docs/01-assignment-name/
├── public/
├── src/
├── index.html
├── package.json
└── vite.config.js
```

Use `00-template/` as the starting shape when creating a new assignment.
This directory is intended to be published by GitHub Pages from `/docs`.
